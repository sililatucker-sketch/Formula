# Formula brand assets

Source files for Formula marketing and social content. The 1024px icons and
the logo are the same files the Formula mobile app ships with
(prv8-app/apps/formula/assets). The 1024px App Store icon lives at the repo
root as app-icon-1024.png.

| File | Size | Use |
| --- | --- | --- |
| formula-logo.png | 2623 x 470 | Horizontal wordmark, transparent background |
| formula-icon-dark.png | 1024 x 1024 | App icon on dark (also the splash and adaptive icon) |
| formula-icon-light.png | 1024 x 1024 | App icon on light |
| formula-icon-transparent.png | 1024 x 1024 | App icon with transparent background |
| favicon.png | 48 x 48 | Browser favicon |
